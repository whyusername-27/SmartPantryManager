### Smart Pantry Manager

### Application Overview:

Smart Pantry Manager is an Android application written in Java designed to help households reduce food waste. The app allows users to track their available kitchen ingredients, monitor expiry dates with visual indicators, and instantly discover recipes that match what they already own through a strict-matching recipe algorithm.

### Database Choice: SQLite(SQLiteOpenHelper)

### Why SQLite was Chosen:

SQLite provides a robust, lightweight, and built-in relational database solution ideally suited for local mobile environments. It allows for reliable structured storage of pantry inventory and pre-seeded recipe data without requiring external server setup or internet connectivity, ensuring fast and secure offline performance
